# 💡 点子库 · ideas_wsy

> **“好想法不是稀缺品，时间和精力才是。”**

这里存放着我因现实原因无法亲自实现的灵感。它们不是完整的商业计划，不是可执行的代码，只是一些**被认真想过的念头**——关于工具、关于系统、关于人与人之间尚未被好好解决的事。

我大概率不会亲自把它们做出来。但这不代表它们应该被忘掉。

**如果你觉得其中某个点子值得变成现实，请随意拿走。做出来了，甚至不需要署我的名——让我知道一声，就够我开心很久了。** 看着别人替自己把想法活出来，也是一种成就。

## 这里有什么、没有什么

**有：**
- 被认真写下来的问题、场景和初步思路
- 一些我知道“值得做但轮不到我做”的东西
- 一个按状态追踪点子的公开看板

**没有：**
- 完整的技术方案或商业计划书
- 承诺“一定会做”的路线图
- 公司内部信息、客户数据、任何密钥或敏感截图

## 如何浏览点子

所有点子都以 **Issue** 的形式存放，点击进入 [Issues](https://github.com/wangshouyong/ideas_wsy/issues) 即可浏览。

建议按标签筛选：

- 想看**马上能上手的小东西** → [`seed`](https://github.com/wangshouyong/ideas_wsy/labels/seed)
- 想看**已经在被琢磨的** → [`exploring`](https://github.com/wangshouyong/ideas_wsy/labels/exploring)
- 想看**暂时搁置但没死的** → [`parked`](https://github.com/wangshouyong/ideas_wsy/labels/parked)
- 想看**已经被判断不值得做的**（附原因） → [`dropped`](https://github.com/wangshouyong/ideas_wsy/labels/dropped)

也可以直接打开 **Projects** 看板，按 `seed → exploring → building → parked/dropped` 的状态流转查看全局。

## 如果你想把某个点子做出来

**直接动手，不需要先问我。** 这些点子本来就是放出来让人拿走的。

如果你愿意，可以在对应的 Issue 下留一句“我来试试”，这样其他人能看到它正在被推进。**做出来了，回来贴个链接**——我会把它加进下面的“已孵化”列表。这就是这个仓库存在的全部意义。

## 如何提交你的点子

这个仓库欢迎其他人提交点子。流程很简单：

1. 点击 [New Issue](https://github.com/wangshouyong/ideas_wsy/issues/new/choose)
2. 选择 **「点子」** 模板
3. 按模板填写，提交即可

提交者**保留署名**。如果点子后来被实现了，功劳是你的。

## 点子模板

一个好的点子 Issue 应该回答清楚四件事，和 CodeLove 的思路一致：**问题是什么、大致怎么解、对谁有价值、还有什么没想清楚**。

```markdown
## 🧩 解决什么问题
一句话说清楚：什么东西现在很烂 / 不存在 / 很贵？

## 💡 初步想法（可留空）
大概可以怎么做。允许只有一个模糊的念头。

## 🎯 对谁有价值
谁会真的用？为什么？

## ❓ 还没想清楚的事
最大的不确定性在哪里？
```

不必填满。但“解决什么问题”这一栏，请认真写。

## 标签体系

| 标签 | 含义 |
|---|---|
| `idea` | 这是一个点子 |
| `seed` | 刚冒出来，还没想清楚 |
| `exploring` | 在琢磨可行性 |
| `building` | 已经有人在做了 |
| `parked` | 暂时搁置，但没放弃 |
| `dropped` | 判断不值得做（**必须写一句为什么**） |
| `area:ai` / `area:tool` / `area:life` / `area:business` | 领域分类 |

`dropped` 的 Issue 不会被删除。**一个被认真放弃的点子，比一个被悄悄删掉的点子有价值得多**——它记录了“为什么此路不通”。

## 原则与约定

- **点子廉价，执行值钱。** 这里的目的不是“攒着一堆想法然后觉得自己很厉害”，而是**别让好想法因为没人动手就烂在脑子里**。
- **不承诺。** 仓库里的点子不构成任何“我会做”的承诺。`parked` 和 `dropped` 是常态，不是失败。
- **公开、安全。** 不放公司 / 客户 / 私密信息，不放密钥、内部截图。提交前自己检查一遍。
- **欢迎拿走，欢迎实现，欢迎告诉我。** 署名归提交者，实现归动手的人，开心归所有人。
- **点子不保证能够技术实现。** 这里是“想象力的许愿池”，不是“硬核工程招标会”。拥抱超前的脑洞，但拒绝违背科学。 这个仓库不承担“技术可行性验证”的责任。允许技术极度超前、允许当前工程无法实现，但拒绝伪科学和反智主义。真正的异想天开，是比时代早走了十年的远见。
