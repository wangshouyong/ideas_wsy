# 点子库 · ideas_wsy

> 记录点子、灵感、想做的工具。这里只存**值得记下来的想法**，不要求方案完整。

## 怎么用

1. 新点子 → **New issue** → 选「💡 点子」模板；
2. 只填「解决什么问题」，方案可以先留空；
3. 加状态标签：`seed` → `exploring` → `building` → `parked` / `dropped`；
4. 不做、暂缓的点子也**保留**（关闭或 `dropped`，写一句为什么）——这比删掉有价值；
5. 想看板：仓库 **Projects** 页开一个 Board，按状态标签分列即可。

## 标签体系

| 标签 | 含义 |
| --- | --- |
| `idea` | 这是一个点子 |
| `seed` | 刚冒出来，还没想清楚 |
| `exploring` | 在琢磨可行性 |
| `building` | 已经在做 |
| `parked` | 暂时搁置 |
| `dropped` | 放弃 / 不值得做（**保留原因**） |
| `area:ai` / `area:tool` / `area:life` / `area:business` | 分类 |

## 一个点子记什么

- **一句话**：这个点子干什么
- **触发场景**：什么时候会觉得"要是有这个就好了"
- **为什么现在**：为什么此刻值得想（可留空）
- **初步想法**：大概怎么做（可留空，允许只有一个念头）
- **下一步**：验证它最小的一步是什么
- **同类 / 参考**：见过的类似产品、文章、讨论

## 注意

- **公开仓库**：不要放公司 / 客户 / 私密信息，不放密钥、内部截图；
- 欢迎别人开 issue 提点子或评论，但**提交者保留署名**；
- 点子是廉价的，执行才值钱——这里的目的是**别让好想法丢掉**，不是承诺都要做。
